# API reference

## Authentication

Unless a route is marked **public**, it requires an authenticated BetterAuth
session. Admin routes (`/api/admin/*`) require the `admin` or `superadmin`
global role. Pass the session cookie (set on sign-in) or an
`Authorization: Bearer <token>` header. Unauthenticated requests receive
`401 AUTH_001`; authenticated requests lacking the required role receive
`403 AUTH_001`.

## BetterAuth

All BetterAuth-managed routes are served under `/api/auth/`. See
[OAuth 2.1 / OIDC](/docs/concepts/oauth-oidc) for the full flow.

| Method | Path | Auth | Description |
|---|---|---|---|
| `ALL` | `/api/auth/*` | varies | BetterAuth handler — sign-in, sign-up, sign-out, sessions, OAuth2, OIDC, MFA, passkeys, social login |
| `GET` | `/api/auth/jwks` | public | JSON Web Key Set |
| `GET/POST` | `/api/auth/oauth2/authorize` | public | Authorization endpoint |
| `POST` | `/api/auth/oauth2/token` | public | Token endpoint |
| `GET` | `/api/auth/oauth2/userinfo` | Bearer | UserInfo endpoint |

## App configuration (public)

| Method | Path | Auth | Description |
|---|---|---|---|
| `GET` | `/api/app-config` | public | Registration policy and enabled social providers. Query param `client_id=<app-slug>`; without it, global defaults are returned. |

## User self-service

All routes require the caller's own session.

| Method | Path | Auth | Description |
|---|---|---|---|
| `GET` | `/api/user/subscription` | session | Own app access list with subscription/plan details |
| `GET` | `/api/user/consumption/:appId` | session | Own consumption aggregates for an application |
| `GET` | `/api/user/sessions` | session | Own active sessions |
| `DELETE` | `/api/user/sessions/:id` | session | Revoke one of own sessions |
| `GET` | `/api/user/organizations` | session | Organizations the user belongs to |
| `PATCH` | `/api/user/profile` | session | Update own profile (`name`, `phone`, `company`, `position`, `address`, `image`) |

## Consumption

| Method | Path | Auth | Description |
|---|---|---|---|
| `POST` | `/api/consumption` | Bearer / session | Record a consumption entry (`{ applicationId, userId, key, value }`) |
| `GET` | `/api/consumption/:userId/:applicationId` | Bearer / session | Aggregates for a user + application |
| `GET` | `/api/consumption/:userId/:applicationId/:key` | Bearer / session | Single aggregate by key |
| `DELETE` | `/api/consumption/:userId/:applicationId/:key` | admin | Reset a consumption counter |
